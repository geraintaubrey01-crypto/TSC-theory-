# TSC-theory-

## Scalar Wave Lab

`scalar-wave-lab/` contains a standalone WebGL2 scalar-wave simulation with GPU finite-difference updates, interactive impulses, damping, and plane, torus, Möbius-strip, and Klein-bottle boundary conditions.

Open `scalar-wave-lab/index.html` in a WebGL2-capable browser. No build step or external dependency is needed. See [the numerical model and topology notes](scalar-wave-lab/MODEL.md) for the equation, implementation, limitations, and possible extensions.
